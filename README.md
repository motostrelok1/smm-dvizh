# SMM Движ — Mind Map

Интерактивный редактор маркетинговой стратегии автошколы «Движ». Работает как статический сайт на GitHub Pages, без сервера и сторонних JavaScript-зависимостей.

## Возможности
- Раскрывать и сворачивать ветки любой глубины.
- Редактировать названия и цвета узлов.
- Добавлять дочерние ветки, удалять узлы с поддеревьями.
- Перемещать карту мышью и менять масштаб.
- Автоматически сохранять карту в localStorage браузера.
- Выгружать и загружать JSON для резервного копирования.

## Запуск
Откройте `index.html` в браузере. Для GitHub Pages адрес по умолчанию: https://motostrelok1.github.io/smm-dvizh/

## Работа с картой
Щёлкните узел, чтобы открыть панель редактирования. Кнопка `＋` создаёт дочерний узел. Стрелка рядом с названием сворачивает/раскрывает ветку. Для просмотра используйте перетаскивание пустого пространства и прокрутку колеса мыши. Для переноса данных между браузерами используйте JSON-экспорт и импорт.

## Хранение и ограничения
Данные сохраняются **только в текущем браузере и профиле устройства** с ключом `smm-dvizh-mindmap-v1`. Другие браузеры или компьютеры их не увидят; очистка данных сайта может удалить карту. GitHub Pages не хранит пользовательские изменения, не предоставляет авторизацию и совместное редактирование. Перед очисткой хранилища делайте экспорт JSON. При импорте текущая карта заменяется после подтверждения.

## Деплой
Workflow `.github/workflows/pages.yml` публикует корень репозитория при изменениях в `main` и доступен для ручного запуска. В **Settings → Pages → Build and deployment → Source** выберите **GitHub Actions**. Затем дождитесь успешного запуска **Actions → Deploy static site to Pages**.
