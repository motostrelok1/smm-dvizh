# Roadmap · SMM Движ

## MVP 1 — реализовано в коде
- Светлая интерактивная mind map.
- Начальная маркетинговая стратегия автошколы.
- CRUD узлов, раскрытие/сворачивание, масштаб и перемещение.
- Локальное автосохранение, импорт/экспорт JSON.
- Статическая публикация через workflow GitHub Pages.

## MVP 1.1 — улучшение редактора
- Перетаскивание узлов между родителями, изменение порядка.
- Undo/redo и корзина удалённых узлов.
- Поиск по карте, сочетания клавиш, адаптивная мобильная компоновка.
- Экспорт PNG/SVG/PDF и печать.

## MVP 2 — несколько карт
- Список карт, шаблоны и дублирование.
- Импорт/экспорт набора карт.
- Задачи, статусы, сроки и ответственные на узлах.

## MVP 3 — командная работа
- Backend с авторизацией и ролями.
- Хранение в БД, журнал изменений, резервные копии.
- Совместная работа и права доступа.

## Важный принцип
Не заявлять серверную синхронизацию до появления backend. GitHub Pages публикует приложение, но не пользовательские изменения.

## MVP 1.2 — редактор узлов (код добавлен 2026-10-18)
- Inline-редактирование названия по двойному клику.
- Создание дочернего и соседнего узла, контекстное меню.
- Перенос ветки с потомками на другую ветку (drag & drop).
- Отмена и повтор действий (Ctrl+Z, Ctrl+Y).
- Увеличенные подписи, минимальный zoom 70%; новые пустые узлы отменяются без следа.

## План по новому ТЗ
- Палитра 8–10 цветов и поле hex.
- Свойства узла: толщина связи, иконка, заметка, URL, статус.
- Поиск и подсветка узлов.
- Шаблоны: пустая карта, воронка, контент-план.
- PNG/SVG/PDF экспорт, тёмная тема, презентационный и канбан-варианты.
- Бюджет, KPI, ответственный, дедлайн и сводные показатели по ветке.

**Примечание:** визуальное требование о неизменном размере шрифта при любом масштабе пока решено только частично нижней границей zoom; полноценный независимый масштаб подписей — отдельная задача. Перенос мышью рассчитан на desktop.
