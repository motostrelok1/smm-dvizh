# Спецификация продукта · MVP 1.0

## Цель
Визуально управлять маркетинговой стратегией автошколы «Движ» как редактируемым деревом идей.

## Сценарии пользователя
1. Открыть готовую маркетинговую карту с шестью направлениями: каналы, контент, продвижение, маркетинговый план, аналитика, воронка.
2. Выбрать узел и изменить его название или цвет.
3. Создать любое число дочерних узлов и уровней; удалить узел с потомками с подтверждением.
4. Свернуть крупные разделы для обзора структуры, затем раскрыть их.
5. Сохранить изменения при перезагрузке того же браузера.
6. Экспортировать документ в JSON и восстановить его импортом.

## Модель данных
Каждый узел: `{id: string, title: string, color: '#RRGGBB', collapsed: boolean, children: Node[]}`. Корень один. ID уникальны. Импорт валидируется (ограничение длины заголовка, глубины, числа узлов, формата цветов и ID).

## UX
Светлая тема; интерактивное горизонтальное дерево; панель редактирования; кнопки глобального раскрытия/сворачивания, масштабирования и центрирования. Не используются внешние API.

## Нефункциональные требования
Быстрая загрузка статического сайта; отсутствие серверных секретов; текст узлов отображается через `textContent` (не выполняется как HTML); импортируемый JSON не исполняется как код.

## Ограничения MVP
Одна активная карта на устройство/браузер; нет серверной синхронизации, истории версий, совместной работы, авторизации или перетаскивания узлов между ветками. JSON — единственный способ переноса карты.

## Критерии приёмки
- Добавленный узел остаётся после обновления страницы.
- Переименования и изменения цвета остаются после обновления.
- Сворачивание скрывает потомков, не удаляя их.
- Удаление корневого узла недоступно.
- Экспортированный JSON успешно импортируется и восстанавливает структуру.
- Сайт доступен по HTTPS после успешного деплоя Pages.
